# License and redistribution audit

**BLOCKS:** none. The shipped software (all 103 linked crates, Rust std, MinGW-w64 runtime, libgcc/libgcc_eh, Moonshine base weights) is redistributable with notices, and the pinned classifier, `hold-classifier-accent-r2`, was trained only on licence-cleared sources.

**NEEDS NOTICE:** MIT crates (100 of 103 elect MIT incl. Unlicense/BlueOak/0BSD/BSD-2/Zlib choices; copyright lines in NOTICE) · Apache-2.0-only crates prost 0.11.9, safetensors 0.6.2 (license text) · zlib-rs 0.6.8 (Zlib; notice only strictly required for source, included) · Rust standard library (MIT + Unicode-3.0 tables in core + musl notices in libm/compiler_builtins) · MinGW-w64 runtime (COPYING.MinGW-w64-runtime.txt clause 2 requires reproduction in binary distributions) · Moonshine base (MIT, "Copyright (c) 2025 Useful Sensors, Inc. (dba Moonshine AI)") · CC BY 4.0 attribution for LibriTTS and VCTK (good practice; whether attribution is legally owed for weights trained on synthetic output is itself uncertain). libgcc: no notice required (GCC Runtime Library Exception), listed for information.

**UNCERTAIN:** Moonshine base upstream training data ("200,000 hours ... collected from the internet") — upstream's risk, published MIT; low.

**Training sources of the pin**, each checked for its licence and its training lineage ([training.md](training.md)):
- eSpeak NG and flite.
- The Piper voices libritts high (CC BY 4.0, trained from scratch); ljspeech, kristin, norman and cori (public domain, trained from scratch); john (public domain, fine-tuned from kristin); no_NO nvcc, sv_SE nst and nl_BE rdh (CC0, trained from scratch); and nl_NL alex (CC0, fine-tuned from rdh).
- The official VITS VCTK model (MIT, trained end to end on VCTK 0.92, CC BY 4.0).
- The simulated and Aachen room responses and the public-domain point-source noises.

`thuum.hold_corpus` voices only that list, `thuum.hold_train` refuses a corpus file from any other voice, and `thuum.hold_train noise` packs only those room responses and noises. The pin is a uniform weight soup of ten runs, each started from Moonshine base.

## Method

- Crates: `cargo metadata --format-version 1 --filter-platform x86_64-pc-windows-gnu --offline --locked` in a copy of `plugin/` (toolchain 1.99.0 via `plugin/shell.nix`), resolve graph walked from the root over `kind == null` edges only. Proc-macro crates (run inside rustc, not linked) and their exclusive deps split out; build-dependency closure listed as tool-only.
- Link: a real release build of the cdylib (`cargo build --release --locked --target x86_64-pc-windows-gnu --lib`, same RUSTFLAGS as shell.nix plus `-Wl,--trace -Wl,-Map`). The map's "Archive member included" section names exactly which native objects entered thuum.dll. Result: dllcrt2.o, crtbegin.o, crtend.o; libmingw32.a (12 members: cinitexe, CRT_fp10, gccmain, mingw_helpers, natstart, pesect, pseudo-reloc(-list), tlsmcrt, tlssup, tlsthrd, usermatherr); libmingwex.a (8: cosl_internal, dllmain, exp2l, internal_logl, ldexp, log2l, powi, sinl_internal); libmsvcrt.a (import stubs + acrt_iob_func/onexit_table/sin/_initterm_e); libgcc.a(_ctors.o); libgcc_eh.a(unwind-seh.o); Windows import libs. **libpthread.a (winpthreads) is on the link line but contributes no member: winpthreads is not in the DLL.** compiler_builtins contributes only Rust objects (no compiler-rt C). DLL imports only Windows system DLLs (kernel32, msvcrt, ntdll, ole32, combase, oleaut32, propsys, shell32, rpcrt4, advapi32, bcrypt, bcryptprimitives, userenv, ws2_32, api-ms-win-*). This is a build at this revision; re-check the map if dependencies change.
- Strings check on the built DLL: it embeds the classifier, its two decoding constants (`word_bonus`, `min_samples` from `data/hold-classifier.json`), `data/shouts.json` whole, including the two word-list source URLs in its `sources`, and `data/game-forms.json`. Its only other URLs come with crate data: getrandom's Node.js error message and the Apache-2.0 header of the NNEF standard library (`stdlib.nnef`, Copyright 2017 The Khronos Group Inc.) that tract-nnef embeds. It carries no machine paths: the classifier export keeps only each node's `fx_node` metadata, and `python3 -m thuum package` refuses a DLL containing a path under a home, temporary, system or Nix store directory.

## Training-data enforcement

- `thuum/hold_corpus.py` names the cleared voices in `PIPER`, `VITS`, `FLITE` and the eSpeak lists, and `cleared()` is what `thuum/hold_train.py` checks each corpus file against; `pack_noise` globs only `air_type*`, simulated RIRs and point-source noises.
- Each of the ten runs in the pin's soup starts from Moonshine base, so no earlier classifier's weights are in it.
- No recording of a person and no game audio trains weights; the word bonus is chosen on synthetic speech.
